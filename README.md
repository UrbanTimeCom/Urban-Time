# ⚡ UrbanTime - Reserva. Organiza. Crece.
### Plataforma de Turnos Inteligentes para Locales y Servicios

UrbanTime es un sistema de gestión y reserva de turnos en tiempo real, diseñado con una experiencia visual minimalista y de alto impacto, compatible con **Web**, **Android** e **iOS**.

---

## 🎨 Especificaciones de Diseño del Mockup
- **Hero Izquierdo**: Paisaje alpino crepuscular entre nubes, atmósfera envolvente con degradados sutiles, métricas en vivo (*24/7 Disponible*, *100% Privado*, *Tiempo Real*) y carrusel de indicadores.
- **Card de Autenticación**:
  - Fondo ambiental suave con iluminación radial lavanda/hielo.
  - Botón principal de **Google Sign-In** con branding oficial.
  - Inputs con iconos minimalistas (*correo* y *contraseña* con revelador de clave).
  - Botón de acción **"Iniciar Sesión →"** con el degradado azul-índigo del mockup.
  - Botones secundarios de **Facebook** y **Apple ID**.
  - Enlaces de recuperación y registro.
- **100% Responsivo Nativo**: Sin barras de emulación ni selectores manuales; la interfaz detecta la pantalla y se adapta fluidamente tanto a pantallas gigantes como a teléfonos móviles.

---

## 📁 Archivos del Proyecto
- 📄 `index.html`: Aplicación lista para producción.
- 🎨 `styles.css`: Estilos, degradados exactos y efectos visuales.
- ⚙️ `app.js`: Manejo de autenticación, roles, formulario y persistencia de sesión.
- 📱 `Mobile-Expo-Template.tsx`: Código fuente nativo en React Native / Expo.
- 🔌 `supabase-firebase-config.js`: Integración de base de datos y OAuth backend.
- 📖 `CAPACITOR-GUIDE.md`: Guía para compilar a APK de Android y Xcode de iOS.
